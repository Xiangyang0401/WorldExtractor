# 万界拾遗

一个文字探索游戏。玩家可以随机抽取或自行命名世界，进入世界后进行5次探索，每次做出选择影响世界的4个维度属性，最终触发不同结局并解锁成就。

---

## 快速启动

```bash
npm install
npm run dev     # 开发模式，访问 http://localhost:5173
npm run build   # 打包输出到 dist/
```

## 游戏设计

### 两种模式

**古卷模式**（离线）
- 2个预设世界：镜渊、拾味集
- 固定事件池，每次随机身份和事件
- 无需任何配置

**无界模式**（AI驱动）
- 玩家自行配置 API URL 和 Key
- 支持随机渡界（随机世界名）或以名造界（自定义名称）
- 世界数据持久化，下次进入同名世界会继承历史

### 核心游戏循环

```
主界面（三栏）
├── 左栏：渡界 / 以名造界 / 渡痕 / 行囊
├── 中栏：世界简介 + 进入/放弃按钮
└── 右栏：四维属性预览

↓ 确认进入

探索界面（左右两栏）
├── 左栏（三层）：
│   ├── 顶部固定：世界名 + 进度条 + 时间 + 离界按钮
│   ├── 中部滚动：事件叙述 / 选择后果 / 余波
│   └── 底部固定：选项按钮 / 确认按钮
└── 右栏：四维属性实时显示（做出选择后立即更新）

↓ 5次探索完成

结局界面 → 成就解锁 → 返回主界面
```

### 探索规则
- 进入探索后不能存档，中途退出（离界）则世界消散
- 退出前有确认弹窗提示
- 每次探索有3-4个选择，选择影响4个专属属性（值域0-100）
- 属性变化在做出选择后立即反映在右侧面板
- 第5次探索后根据属性值触发对应结局

### 成就系统（渡痕）
- 每次完整探索产生一条成就记录
- 记录内容：世界名、时间、身份、结局、探索历史摘要、世界终态属性
- 点击成就可展开查看详情

## 无界模式：AI 生成逻辑

### 核心设计：框架 + 事件分离

**世界框架**（`WorldFrame`，只生成一次，永久缓存）
- 世界简介、4个属性定义、2个身份、2-3个结局
- 存入 IndexedDB 的 `worldData` 表
- 下次进入同名世界直接复用，不重新生成

**探索事件**（每次进入时重新生成，基于历史演变）
- 5个探索事件，每个事件有叙述、3-4个选项、余波
- 生成时传入历史状态（探索次数、上次结局、当前属性值）
- AI 基于历史上下文生成延续性事件，让玩家感受到世界在真实演变

### 完整流程

```
输入世界名
    ↓
查 IndexedDB：有无已存框架？
    ├── 有 → 直接复用框架
    └── 无 → AI 生成框架 → 存入 IndexedDB
    ↓
查 IndexedDB：有无历史状态？
    ├── 有 → 传给 AI（探索次数、上次结局、属性值）
    └── 无 → 首次进入，无历史上下文
    ↓
AI 生成本次5个探索事件（基于框架 + 历史）
    ↓
组合成完整 WorldData 展示给玩家
    ↓
玩家探索完成 → 更新历史状态到 IndexedDB
```

### IndexedDB 表结构

| 表名 | key | 内容 |
|------|-----|------|
| `achievements` | id | 成就记录 |
| `worldHistory` | worldId | 世界历史状态（属性、结局、探索次数） |
| `worldData` | id | 世界框架（框架数据按 name 查询） |

## 当前待解决问题

### AI 返回 JSON 解析失败（高优先级）

**现象**：AI 返回内容中有时包含中文书名号引号 `「」` 出现在字符串值内部，或裸换行符，导致 JSON 解析失败。

**当前处理**：`safeParseJSON` 函数做了以下预处理：
1. 提取 `{...}` 或 `[...]` 区间
2. `escapeStringValues` 逐字符扫描，转义字符串内部裸换行
3. 替换中文双引号 `""` 为英文引号

**已知问题**：`「」` 不能简单替换为 `"`，否则会截断 JSON 字符串。目前 `escapeStringValues` 只处理换行，不处理 `「」`，因此当 AI 在字符串内用 `「」` 包含文字时，这些字符会被保留（JSON 合法），不会导致解析失败。

**下次排查方向**：
- 在 Console 里查看 `[万界拾遗] 完整原始内容:` 的完整输出
- 找到 pos 位置对应的具体字符，确认到底是哪类字符导致失败
- 考虑在 Prompt 里明确禁止 AI 使用 `「」`，改用普通引号

### 世界继承验证（待确认）

**现象**：第二次输入同名世界，不确定是否真的在读取本地框架和历史状态。

**下次排查方向**：
- 查看 Console 里 `[万界拾遗] 本地框架:` 和 `[万界拾遗] 历史状态:` 的输出
- 确认第一次探索完成后 `saveWorldFrame` 和 `saveWorldHistory` 是否成功执行
- 检查 `getWorldFrameByName` 按名称查询的逻辑是否正确匹配

## 预设世界内容

### 镜渊
- **核心主题**：真实与倒影，怀疑与确认
- **四维属性**：清醒度、信任度、怀疑值、光感
- **两个身份**：桥守、台老
- **三个结局**：两界相认、镜渊的真相、永静之渊
- **5次探索**：静水第十七年，围绕中央石台裂缝展开

### 拾味集
- **核心主题**：味道与记忆，失去与放下
- **四维属性**：记忆深度、缘分、失落感、当下感
- **两个身份**：过客、寻味者
- **三个结局**：自己的滋味、拾味人、留给世界的气味
- **5次探索**：无年无月，围绕气味与记忆展开
